## Коллекция данных ENOBD: **El Niño Ocean Buoy Dataset**

\* Набор данных океанографических и метеорологических наблюдений с сети буёв TAO/TRITON в тропической части Тихого океана, охватывающий ключевые параметры, связанные с явлениями Эль-Ниньо и Ла-Нинья.

------

### Ссылка на данные

- Ссылка* для загрузки данных (включает дополнительное текстовое описание и метаданные): [link>>](https://ml4es.ru/links/enobd)

------

### Формат и структура файлов

- Формат: `DAT` (ASCII текстовый формат)
- Десятичный разделитель: точка `.`
- Каждая строка соответствует одному наблюдению с конкретного буя в определённое время.

------

### Переменные

| Имя столбца    | Единицы | Описание                                                     |
| -------------- | ------- | ------------------------------------------------------------ |
| `date`         | —       | Дата и время наблюдения (UTC)                                |
| `latitude`     | °       | Географическая широта положения буя                          |
| `longitude`    | °       | Географическая долгота положения буя                         |
| `zon_winds`    | m/s     | Зональная (восточно-западная) компонента скорости ветра      |
| `mer_winds`    | m/s     | Меридиональная (северо-южная) компонента скорости ветра      |
| `humidity`     | %       | Относительная влажность воздуха                              |
| `air_temp`     | °C      | Температура воздуха                                          |
| `s_s_temp`     | °C      | Температура поверхности океана (Sea Surface Temperature, SST) |
| `subsurf_temp` | °C      | Температура подповерхностных слоёв океана (разные глубины, если доступны) |

------

### Объем и охват

- **Период:** около 1980–1998 гг.
- **Дискретность:** от 1 суток (для большинства переменных) до более высокой частоты на отдельных буях
- **Число записей:** ≈ 178 000 строк
- **Покрытие:** сеть экваториальных буёв (около 70 станций) в Тихом океане (±10° широты, 95°E – 80°W долготы)

------

### Качество данных и особенности

- Колонки в файлах данных не поименованы, файлы содержат только сами значения
- **Пропуски:** в данных присутствуют отсутствующие значения (обозначены как `.` или `NA`), связанные с неполной работой отдельных буёв.
- **Выбросы:** возможны аномальные измерения из-за сбоев оборудования или дрейфа буя.
- **Гетерогенность:** разные буи запускались в разное время, поэтому временные ряды по станциям имеют разную длину.
- **Сезонность и тренды:** данные фиксируют межгодовую изменчивость климата, включая сильные события Эль-Ниньо (например, 1982–83, 1997–98 гг.).
- **Мультиколлинеарность:** отдельные переменные (например, температура воздуха и температура поверхности океана) имеют сильную положительную корреляцию.
