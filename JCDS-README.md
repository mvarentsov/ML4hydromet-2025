## Коллекция данных JCDS: **Jena Climate Dataset**

\* Многолетний метеорологический временной ряд наблюдений, зарегистрированный на территории кампуса Института биогеохимии Макса Планка (г. Йена, Германия).

------

### Ссылки на данные

- Ссылка на загрузку данных: [link>>](https://ml4es.ru/links/jcds)

------

### Формат и структура файлов

- Формат: `CSV`
- Разделитель полей: запятая `,`
- Десятичный разделитель: точка `.`
- Каждая строка — одно 10-минутное наблюдение.

------

### Переменные

| Имя столбца       | Единицы    | Описание                                                 |
| ----------------- | ---------- | -------------------------------------------------------- |
| `Date Time`       | —          | Дата и время в UTC                                       |
| `p (mbar)`        | мбар       | Давление на уровне станции                               |
| `T (degC)`        | °C         | Температура воздуха                                      |
| `Tpot (K)`        | K          | Потенциальная температура                                |
| `Tdew (degC)`     | °C         | Температура точки росы                                   |
| `rh (%)`          | %          | Относительная влажность                                  |
| `VPmax (mbar)`    | мбар       | Максимально возможное парциальное давление водяного пара |
| `VPact (mbar)`    | мбар       | Фактическое парциальное давление водяного пара           |
| `VPdef (mbar)`    | мбар       | Дефицит парциального давления водяного пара              |
| `sh (g/kg)`       | г/кг       | Удельная влажность                                       |
| `H2OC (mmol/mol)` | ммоль/моль | Объемная концентрация водяного пара                      |
| `rho (g/m**3)`    | г/м³       | Плотность воздуха                                        |
| `wv (m/s)`        | м/с        | Средняя скорость ветра за 10 мин                         |
| `max. wv (m/s)`   | м/с        | Максимальная скорость ветра за 10 мин                    |
| `wd (deg)`        | °          | Направление ветра                                        |

------

### Объем и охват

- **Период:** 2009–2016 (включительно)
- **Дискретность:** 10 минут
- **Число записей:** ≈ 420 000 строк
- **Покрытие:** одна наземная станция (г. Йена, Германия)

------

### Качество данных и особенности

- **Пропуски:** встречаются отдельные отсутствующие значения (обычно кратковременные).

- **Выбросы и аномалии:** возможны аномалии, резкие пики (например, в ветре или давлении).

- **Сезонность:** выраженные суточная и годовая цикличности большинства переменных.

- **Автокорреляция:** заметные связи между соседними временными отсчетами.

- **Согласованность переменных:** часть показателей (например, переменные, связанные с влагосодержанием) избыточны и сильно коррелированы.
