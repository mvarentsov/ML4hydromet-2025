## Набор данных BMSAQD: **Beijing Multi-Site Air Quality Dataset**

\* Набор данных наблюдений за качеством воздуха и метеорологическими условиями на нескольких станциях в Пекине (Китай).

------

### Ссылка на данные

- Ссылка* для загрузки полной коллекции данных: [link>>](https://ml4es.ru/links/bmsaqd)

------

### Формат и структура файлов

- Формат: `CSV`
- Разделитель полей: запятая `,`
- Десятичный разделитель: точка `.`
- Каждая строка соответствует одному часу наблюдений на одной станции.

------

### Переменные

| Имя столбца | Единицы | Описание                                                     |
| ----------- | ------- | ------------------------------------------------------------ |
| `No`        | —       | Порядковый номер записи                                      |
| `year`      | —       | Год наблюдения                                               |
| `month`     | —       | Месяц                                                        |
| `day`       | —       | День                                                         |
| `hour`      | —       | Час наблюдения (UTC+8)                                       |
| `station`   | —       | Название станции (одна из 12 станций в Пекине и пригородах)  |
| `PM2.5`     | µg/m³   | Концентрация взвешенных частиц диаметром менее 2.5 мкм       |
| `PM10`      | µg/m³   | Концентрация взвешенных частиц диаметром менее 10 мкм        |
| `SO2`       | µg/m³   | Концентрация диоксида серы                                   |
| `NO2`       | µg/m³   | Концентрация диоксида азота                                  |
| `CO`        | mg/m³   | Концентрация угарного газа                                   |
| `O3`        | µg/m³   | Концентрация озона                                           |
| `TEMP`      | °C      | Температура воздуха                                          |
| `PRES`      | hPa     | Атмосферное давление на уровне станции                       |
| `DEWP`      | °C      | Температура точки росы                                       |
| `RAIN`      | mm      | Количество осадков за час                                    |
| `WSPM`      | m/s     | Средняя скорость ветра                                       |
| `wd`        | —       | Направление ветра (категориальное значение, например, NW, SE и т. д.) |

------

### Объем и охват

- **Период:** март 2013 г. – февраль 2017 г.
- **Дискретность:** 1 час
- **Число записей:** ~1 000 000 строк (суммарно по всем станциям)
- **Покрытие:** 12 станций мониторинга в Пекине и пригородах

------

### Качество данных и особенности

- **Пропуски:** встречаются отсутствующие значения (`NA`) в отдельных переменных и временных интервалах.

- **Выбросы:** возможны экстремальные значения загрязняющих веществ (сильные эпизоды смога).

- **Сезонность:** выраженные сезонные различия в загрязнении (зимой концентрации выше, летом ниже).

- **Гетерогенность:** показатели различаются между станциями в зависимости от их расположения (центр города, пригородные зоны).
