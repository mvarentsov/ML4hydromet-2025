## Коллекция данных **Crowdsourced Mapping**

*Данные из OpenStreetMap используются для автоматической классификации спутниковых изображений по видам земельного покрова.*

------

### Ссылка на загрузку данных

- Ссылка для загрузки данных: [link>>](https://ml4es.ru/links/scmap)

------

### Формат и структура данных

- Формат: **CSV**
- Два файла:
  - `training.csv` — тренировочные данные с возможными ошибками в разметке.
  - `testing.csv` — тестовые данные для оценки моделей.
- Каждая строка — объект (сегмент пикселей), для которого рассчитаны спектральные признаки Landsat и задана метка класса.

------

### Переменные

| Имя столбца | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| признаки    | Числовые признаки, извлечённые из Landsat-изображений (спектральные индексы) |
| `class`     | Класс земного покрова: `farm`, `forest`, `grass`, `water`, *etc.* |

------

### Объем и охват

- **Временной диапазон:** Январь 2014 - Июль 2015
- **Географический охват:** область с полигонами OpenStreetMap (точная территория не указана).
- **Размерность:** 10545 строк

------

### Качество данных и особенности

- **Шум в разметке:** тренировочные метки могут содержать ошибки из-за неточностей OSM.
- **Классовый дисбаланс:** распределение по классам неравномерное.
- **Природа данных:** данные являются результатом объединения спутниковых изображений Landsat и краудсорсинговой разметки.
- **Пропущенные значения**: нет
