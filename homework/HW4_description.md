# Домашнее задание #4. </br> Оценка качества и неопределенностей модели МО на примере линейной регрессии

Задание посвящено применению подхода кросс-валидации для оценки качества и неопределенностей (качества, параметров, результатов расчета) модели машинного обучения на примере линейной регрессии в рамках подхода кросс-валидации (скользящего контроля).

В задании необходимо:
1. Дополнить решение выбранной вами задачи машинного обучения ([домашнее задание №3](https://github.com/mvarentsov/ML4hydromet-2025/blob/main/homework/HW3_description.md)) реализацией подхода кросс-валидации. При это нужно обосновать выбор оптимального метода кросс-валидации для вашей задачи (bootstap, k-fold, stratified k-fold и т.д.). Можно использовать как готовые решения из библиотеки `scikit-learn`, так и реализовать алгоритм кросс-валидации самостоятельно.    
2. С использованием выбранного подхода кросс-валидации оценить неопределенность (в терминах выбранной вами **меры неопределенности**, которую нужно явно обозначить - например, стандартное отклонение, доверительные интервалы заданного уровня значимости и пр.):
   - метрик качества модели
   - параметров модели (коэффициентов регрессии $\theta$ для наиболее важных, на ваш взгляд, предикторов)
   - результатов расчета целевой переменной для выбранного события/событий (например, для показательного временного периода)
3. Сравнить метрики качества модели и их неопределенность при использовании как минимум одного альтернативного метода кросс-валидации (например, сравнить выбранный вами метод со стандартным shuffle split)
4. В рамках подхода кросс-валидации исследовать, являются ли следующие изменения метрик качества модели при следующих преобразованиях исходных данных статистически значимыми:
   - масштабирования данных (стандартизации или нормализации)
   - порождения новых признаков
5. **Бонусная часть**: Реализовать алгоритм генерации тренировочных и тестовых выборок для выбранного вами метода кросс-валидации как класс с методом-генератором `split`, совместимый с функциями [`cross_val_score`](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.cross_val_score.html) и [`cross_validate`](https://scikit-learn.org/1.5/modules/generated/sklearn.model_selection.cross_validate.html) библиотеки [`scikit-learn`](https://scikit-learn.org/1.5/index.html). 

**Особенности выполнения данного задания**:
- Поскольку задание №4 тесно связано с заданием №3, их можно сделать и сдать вместе, как один jupyter-ноутбук без дублирования однотипных частей задачи. Если не сдавать задание №3 отдельно, и сдать своевременно задание №4, штраф за позднюю сдачу не будет применяться. 
- В задании №3 было ограничение на использование конвейера обработки данных (Pipeline) и готовыми функциями для кросс-валидации (`cross_validate`, `cross_val_score`) библиотеки sklearn. В задании №4 такого ограничения нет. Если делать и сдавать оба задания вместе, то должна быть часть про применение линейной регрессии и оценку ее качества без использования этих инструментов. 
- Выполнение бонусной части позволит получить бонусный балл сверх оценки за задание.
